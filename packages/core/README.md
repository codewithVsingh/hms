# Domain boundaries

The portal uses `apps/portal/lib/server` for the trusted auth/payment integrations and `apps/portal/app/api/v1/[...action]/route.ts` for request validation/dispatch. Database-enforced domain services, locks and permission checks are implemented as narrowly scoped RPCs in `supabase/migrations/006–010` (full timestamped filenames). The per-domain folders remain reserved for extraction into a shared server-only core package as the system grows. No unsupported claim is made that every clinical, notification or document module is implemented. Keep the UI, integration adapters and SQL transaction boundaries separate. See docs/API.md.
